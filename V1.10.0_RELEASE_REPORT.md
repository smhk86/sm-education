# SM SCHOOL AI v1.10.0 — Content depth pack

## Scope
Raise the thinnest part of the exercise bank. Before this release 64 of the 105 indexed grade/subject pairs had only 11 exercises (3 per term in the weakest terms). No new feature, API route, AI provider or external data flow is introduced.

## Delivered
- 192 new platform-authored multiple-choice exercises: 3 per pair, one in each term, for the 64 pairs that had exactly 11 items.
- Stages covered: primary (grades 1, 2, 4, 5 — 24 pairs), middle (grades 1, 3, 4 — 24 pairs), secondary (grades 2, 3 — 16 pairs).
- English and French subject items are written in English and French (21 each); the rest are Arabic (150).
- Difficulty is mixed (beginner / intermediate / advanced); correct-answer positions are balanced deterministically (0: 66, 1: 70, 2: 56).
- Exercise bank 1,389 → 1,581; minimum per indexed pair 11 → 12; coverage report regenerated (version 1.10.0).
- `tools/build_v1_10_depth_pack.py` merges the pack idempotently (re-running produces byte-identical files); content lives in `tools/v1_10_content_primary.py`, `_middle.py`, `_secondary.py`.
- Version metadata (package, API, README, manifest, footer) set to 1.10.0; PWA cache key changed to `sm-school-ai-v1.10.0-content-depth` so installed apps refresh the larger bank.

## Safeguards
- Every item is marked `platform_practice_not_official`, `official_sequence_verified: false` and `content_origin: platform_authored_depth_pack_v1.10.0`.
- Secondary items carry `secondary_pathway_alignment` with no pathway assigned.
- Language and editorial review remain `pending_human_editorial_review`; teacher review is required before classroom use.
- Mathematics and informatics were not in the 11-item tier and are unchanged.
- New items are checked against all existing questions in the same grade/subject pair (exact and punctuation-normalised); two candidate questions that duplicated existing ones were replaced.
