# SM SCHOOL AI v2.1.0 — modern platform and stability report

## Scope
This release is a focused modernization pass on the supplied v2.0.0 project. It preserves the existing FastAPI backend, local learner data, AI provider integrations, parent workflows, curriculum assets and Tasnim library.

## Changes
- Active version metadata synchronized to 2.1.0 in package.json, FastAPI, health/catalog API responses, PWA manifest, footer and service-worker cache key.
- Added a compact online/offline status indicator with accessible live-region semantics.
- Added a keyboard skip link to the main content.
- Improved mobile safe-area spacing, touch interaction, keyboard focus, responsive header behavior and reduced-motion support.
- Corrected the service worker fallback so only navigation requests receive the offline app shell. Missing JSON, JavaScript and other assets no longer receive index.html, avoiding misleading JSON parse failures.
- Updated stale PDF API and release-integrity test expectations.

## Audit findings retained as explicit limitations
- The curriculum integrity audit currently reports zero officially verified grade/subject progression pairs. Platform-authored practice must not be presented as Ministry-verified content.
- The Tasnim fetch workflow has offline tests, but this environment cannot confirm a complete live-site download or validate every remote Google Drive file.
- Android APK compilation and real-device/WebView testing require an Android SDK and physical-device validation outside this environment.
- A passing automated suite does not prove that a live Groq/Groq key, deployed API endpoint or network connection is configured on the user's device.

## Validation
See the test execution summary delivered with this archive. Backend integration tests depend on the installed Python dependencies. No live credentials are embedded in the project.

- `npm test`: PASS (full configured suite, including 44 test files).
- `node --check`: PASS for all 30 top-level frontend JavaScript files.
- `python -m compileall`: PASS for backend, tools and tests.
- Curriculum audit: 105 grade/subject records and 1,581 exercises; 0 errors, 0 warnings, and 0 officially verified progression pairs.
- The Python runtime emitted a spreadsheet warmup warning from the execution environment; it did not affect test results.
