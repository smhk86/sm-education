# SM SCHOOL AI v1.13.0 — Home Learning Command Centre

## Scope
Build a local-first home-learning workspace on top of v1.12.0 without claiming unverified Ministry curriculum alignment.

## Delivered
- Added a dedicated Home Learning Centre navigation page.
- Added local homework/task tracking with subject, optional due date, completion and deletion.
- Added configurable daily revision-minute goal.
- Added reusable question/answer flashcards for active recall.
- Added two safe, local interactive learning activities: percentage calculation and average speed.
- Added an explicit curriculum content provenance workflow: draft, under verification, verified; source and page must be recorded before official labelling.
- Added study-centre data to local backup export/import.
- Added the new module to the service-worker cache and bumped cache version.
- Preserved all v1.12.0 files and features.

## Curriculum integrity
No new content is represented as officially approved. Existing curriculum mapping still requires comparison against the current official annual progressions and school textbooks by grade, subject, term, competency, source and page.

## Known limitations
- The new planner and flashcards are stored locally in the browser/device; they are not yet synchronized between family devices.
- Simulations are introductory activities, not full virtual laboratories.
- This release does not claim complete official BEM/BAC coverage.
- Android APK build must be run in an Android/Gradle environment.
