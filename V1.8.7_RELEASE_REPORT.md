# SM SCHOOL AI v1.8.7 — Family weekly learning plan

## Scope
Improve the existing family planner and weekly parent reporting without creating duplicate dashboards or uploading student learning records.

## Delivered
- Added `familyWeeklyFocus`, a learner-isolated recommendation helper using recorded outcomes and grade subjects.
- Prioritizes subjects with at least three recorded answers and accuracy below 60%; otherwise suggests consolidation where evidence exists, and explicitly reports insufficient evidence when it does not.
- Added a print-friendly weekly report that can be printed or saved as PDF through the browser.
- Added a next-week focus panel and print/PDF action to each learner's family planner card.
- Retained existing schedules, local completion tracking, sharing, CSV export and multilingual UI.
- Bumped app/API/PWA metadata and cache key to v1.8.7.

## Privacy
All recommendation calculations use existing local learner records. No new student data is sent to the backend or any third party.

## Validation
- Full `npm test` suite.
- Python bytecode compilation and ZIP integrity checks.
- APK build is not included in this source ZIP.
