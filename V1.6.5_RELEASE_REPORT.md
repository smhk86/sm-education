# SM SCHOOL AI v1.6.5 — Release report

## Scope delivered
- Added up to 20 local learner profiles in the Parents area.
- Added profile selection, grade association, add/delete controls and confirmation before deletion.
- New learning activity and test history are tagged to the active learner.
- Parent dashboard statistics, subject performance, recent activity and CSV export are scoped to the active learner.
- Legacy activity records without a learner ID remain associated with the default learner profile.
- Learner profiles and active profile selection are included in the local JSON backup/restore allowlist; imported learner profiles receive structural validation.
- Profile and learning data remain on-device; no account system or cloud synchronization is claimed.

## Preserved
- Existing 1,329 exercise bank, 327 term papers, 342 integrative situations and existing content indexes.
- Existing AI tutor and backend API contracts.
- Existing offline PWA assets and Android Capacitor wrapper.

## Verification performed
- `node --check web/app.js` — passed.
- `python -m py_compile backend/app/main.py tests/*.py` — passed.
- `npm test` — passed: frontend smoke suite, 5 curriculum API tests, PDF/API/rights-gate test suite, release-integrity checks.
- ZIP integrity and extracted-package tests — to be recorded after final archive verification.

## Known limitations
- Profiles are local to this browser/app installation and are not password-protected or synchronized between devices.
- Existing mistake-review and revision-planner stores are still grade/subject scoped rather than fully learner-scoped; the new parent progress and test-history views are learner-scoped.
- Educational content retains its existing platform-authored/provisional status and is not relabelled as officially ministry-verified.
