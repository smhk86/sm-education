# SM SCHOOL AI v1.8.2 — Release report

## Scope
Multi-learner family and teacher overview built on v1.8.1. The release adds a unified local dashboard while preserving existing server behavior.

## Delivered
- Family/class overview across locally configured learner profiles.
- Per-learner 30-day activity and answer counts, accuracy, subjects needing support (only with at least five recorded answers), and advisory exam-readiness status using the existing evidence threshold.
- Direct navigation to each learner profile.
- CSV export for all learner summaries.
- Arabic, French and English labels.
- Explicitly descriptive comparison; no ranking, diagnosis, or predicted grade.
- No new backend endpoint, external data transfer, or server behavior change.

## Validation
- `npm test` includes the new family dashboard regression test.
- JavaScript syntax checks across `web/*.js`.
- Python compilation checks across backend, tests and tools.
- ZIP archive integrity verified.
- Android APK build is not included in this source ZIP.
