# SM SCHOOL AI v1.8.8 — Adaptive learning trends and spaced review

## Scope
Improve the existing adaptive learning tracker using only learner activity already stored locally. No new backend endpoints or external AI calls are introduced.

## Delivered
- Added a per-subject comparison between the most recent 7 days and the preceding 7 days. A trend is shown only when both windows contain at least three scored answers.
- Added four trend outcomes: improving, declining, stable and insufficient evidence. The comparison is advisory and does not replace the existing overall accuracy classification.
- Weekly adaptive plans now choose differentiated activities for support, improving, mastered and evidence-building states.
- Each plan session stores its strategy, observed trend, recommendation reason, source accuracy and spaced-review day.
- Updated the progress panel with trend labels and recent-period evidence in Arabic, French and English.
- Updated package, API, PWA cache, manifest and release documentation to v1.8.8.

## Privacy and compatibility
- All calculations use existing local progress records for the active learner. No new student data is sent to the backend, Groq or another provider.
- Existing backup keys and schema remain unchanged; old adaptive plans remain readable.
- v1.8.7 family reporting, encrypted parent transfer, local backup restore, offline shell and full source tree are retained.

- Automated tests and source syntax checks are recorded in the delivery validation summary.
- Android APK compilation is not claimed as part of this source ZIP.
