# SM SCHOOL AI v1.7.9 Release Report

## Scope
Integrated educational intelligence workspace building on v1.7.8 without replacing existing backend services or curriculum libraries.

## Implemented
- Integrated initial diagnostic tests using available grade/subject practice-bank questions; no fabricated questions are used.
- Learner-scoped mistake capture stored locally and linked to targeted remediation prompts.
- Personalised remedial lesson generation through the existing `/api/v1/ai/tutor` service.
- Detailed written-answer feedback UI using the existing tutor evaluate task; server prompt now requests structured feedback, missing-point analysis, a suggested rubric, model answer and next steps.
- Term-exam simulation UI reusing `/api/v1/learning/exam-builder`, retaining exact grade/subject/term/language matching and separate student/teacher versions.
- Updated PWA cache namespace and release metadata to v1.7.9.

## Important limitations
- AI lesson generation and written-answer evaluation were previously server-configured; in v2.1.1 they use the in-app Groq connection.
- Diagnostic questions are drawn from the current platform practice bank; coverage depends on verified question availability for the selected grade and subject.
- Mock term papers are platform practice material, not official Ministry examinations. The existing curriculum verification warnings remain visible.
- Learner progress and captured errors remain local to the device, consistent with the existing application model.

## Validation
- JavaScript syntax checks and Python compilation run.
- Full regression suite run; APK build is not claimed unless Android toolchain build is executed separately.
