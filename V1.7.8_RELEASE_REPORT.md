# SM SCHOOL AI v1.7.8 Release Report

## Scope
This release adds a dedicated Smart Teacher workflow while preserving the full v1.7.7 source tree and existing learning content.

## Implemented
- Smart Teacher navigation entry and dedicated workspace.
- Active learner identity and local progress summary.
- Subject selection for the learner's current grade.
- Reuse of existing verified-in-app starter lesson cards when a subject/grade match exists.
- Reuse of existing subject practice questions; no synthetic questions are created when a bank is absent.
- Adaptive question ordering based on recorded accuracy.
- Local learner-scoped assessment history and duplicate-submit protection.
- Regression test for the Smart Teacher module.

## Validation
- `npm test`: all existing suites and the new Smart Teacher regression suite passed.
- `node --check web/app.js` and `node --check web/smart-teacher.js`: passed.
- `python -m py_compile backend/app/main.py`: passed.
- PWA offline asset list includes `smart-teacher.js`.
- APK compilation was not run and is not claimed by this release.
