# SM SCHOOL AI v1.18.1 — Competency-based pedagogical session cycle

## Implemented
- Weekly planner sessions now carry a five-stage learning pathway: activation/prior knowledge, guided construction/discovery, guided practice, integration/problem situation, and formative assessment/remediation.
- Session minutes are allocated across the five stages with positive integer durations and an exact total equal to the session duration.
- Learners can check off each pedagogical stage independently; stage progress is saved with the learner-scoped weekly plan.
- Existing v1.18.0 plans remain readable; missing stage data is added when rendered. The existing local storage key is retained.
- Generated five-subject weekly plans distribute the entered daily time across the five sessions rather than assigning the full daily allowance to every subject.
- PWA cache key and asset list updated; package, footer, and release metadata advanced to v1.18.1.

## Educational scope
This is a platform-designed learning workflow inspired by competency-based teaching practices. It is not a reproduction of an official ministry lesson plan, timetable, or subject-specific progression. Teacher validation and alignment against current official documents remain required.

## Validation
- Dedicated regression test covers syntax, required pedagogical stages, positive durations, and exact time conservation for 15–360 minute sessions.
- Full project test suite status is recorded separately after execution; Android build/device validation is not claimed unless performed.
