# SM SCHOOL AI v1.14.0 — Curriculum integrity and release update

## Scope
- Added a deterministic curriculum-data integrity audit for the 2026–2027 registry and exercise bank.
- Checks record identity, academic-year consistency, term mapping completeness, source requirements for any official claim, multiple-choice answer integrity, and exact normalized duplicate questions.
- Emits `web/data/curriculum-integrity-audit-2026-2027.json` with input SHA-256 fingerprints.
- The audit explicitly does not certify Ministry alignment or promote platform-authored material to official status.
- Updated release metadata and service-worker cache version to v1.14.0.

## Validation
Run `npm test` and `npm run audit:curriculum`.

## Known limitations
- No current-year annual progression is marked officially verified by this automated process.
- Ministry document review remains a human evidence task requiring document title, exact page, date, grade, subject, term, and teacher review.
- APK build is not claimed by this release report.
