# SM SCHOOL AI v2.0.0 — release report

## Fixed (from the v1.19.0 test feedback)
| Request | What changed |
|---|---|
| Smart assistant / smart teacher not working | Assistant: local mode answers with no key (lesson + examples + practice + keyword marking); Groq or Groq key optional. Teacher: pool now comes from the exercise bank for the learner's grade and subject (it only used a tiny legacy list before, so most subjects showed "no questions"). |
| Too many archive / PDF links, most dead | Deleted `school-assessments-archive`, `exam-archive`, `pdf-acquisition`, `external-exam-library` data (1,300+ links) and every loader/panel for them. |
| Exercises / test bank not at level | 54 generic "how do you check your solution" template questions removed; repeated cross-grade questions kept only in the lowest grade; 132 new maths questions (3AP / 2AM / 1AS) generated with computed answers. |
| Test-bank UI complexity | One builder (grade, subject, term, count) + three clear actions + Tasnim card + history. Subjects with fewer than 4 questions are hidden. |
| Download Tasnim exams | `tools/fetch_tasnim.py` (run on your computer, requires `--confirm-permission`). The app lists the downloaded files offline. |

## Not done / honest limits
- Files were NOT downloaded from Tasnim: the build environment has no internet. The fetch tool was rewritten against the verified 3-level page layout (grade → subject → paper post → Google Drive link) and passes an offline test with a fake local site, but it has not been run end to end against the live site or real Google Drive. Run `--discover-only` first to check it.
- Content depth: after removing padding, non-maths subjects in the pilot grades are thin (for example 3AP Arabic 4 questions, 2AM Arabic 2, 1AS Arabic 2). These need real, curriculum-checked questions from the textbooks; this build does not invent them.
- Not run: Python/backend tests (FastAPI not installed here), Android APK build, device testing. Backend archive routes still exist but have no data files.
- Node tests run: the full node suite passed except legacy assertions about the removed archive features, which were deleted/neutralised (see tests/smoke_test.js comments) and replaced by `tests/v2_pro_test.js`.
- In-app Tasnim library: tested with a fake index and files (Node), not on a real Android device. Inline PDF display inside an Android WebView is not guaranteed on every device; the viewer therefore always offers 💾 save/share as the fallback, and Word files are save-only.
