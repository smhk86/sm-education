# SM SCHOOL AI v1.18.2 — Teacher-authored competency lesson planner

## Implemented
- Added an Arabic-first lesson preparation panel to the Smart Teacher page.
- Teacher supplies grade, subject, lesson title, target competency, prior learning, resources, and duration.
- Creates an editable five-stage lesson plan: activation, learning construction, guided practice, integration, and formative assessment/remediation.
- Allocates positive integer minutes across the five stages while preserving the exact session duration (15–240 minutes).
- Saves up to 50 lesson plans locally and supports reopening and printing.
- Explicitly labels plans as editable teaching aids requiring teacher validation against current official documents; it does not fabricate ministry-aligned competencies or curriculum progressions.
- Updated package metadata, PWA cache key/assets, and release footer to v1.18.2.
