# SM SCHOOL AI v1.11.0 — Legacy duplicate cleanup

## Scope
Resolve the known legacy issue reported in v1.10.0: 16 groups (20 redundant records) repeated a question inside the same grade/subject pair. No new feature, API route, AI provider or external data flow is introduced.

## Delivered
- 20 redundant exercises replaced by new platform-authored multiple-choice items (informatics ×8, Islamic education ×1, secondary physical sciences ×3, middle-school physics and technology ×8). Each group keeps one original record; only the later records change.
- Record ids, grade, subject, term, topic and lesson are preserved, so the bank stays at 1,581 records and every reference from term exams and integrative assessments remains valid.
- Embedded answer keys synchronized: 19 term-exam papers (`answer_key`) and 19 integrative situations (`model_solution`). One replaced record (INF169-06-10) is not used by any paper.
- Papers that contained both members of a duplicate pair (for example 06-0177 and 14-0049 in the same first-year middle informatics paper) now contain two different questions.
- Duplicate detection ignores diacritics, punctuation, quotes and alef forms; the build tool asserts that exactly the 16 known groups exist before the change and none afterwards.
- Replaced records carry `content_revision` (`version`, `reason`, `origin`, `replaces_duplicate_of`); `content_origin` is unchanged so the v1.4.1 term pack still counts three items per pair (315 total).
- Replacement answer positions are balanced (0: 7, 1: 6, 2: 7). Difficulty and cognitive-process metadata were set to match the new questions: six records changed cognitive process, and three changed difficulty (14-0069 and 14-0228 from advanced to intermediate, 14-0115 from beginner to intermediate).
- `coverage-report` version 1.11.0 with `totals.legacy_duplicates_replaced_v1_11`; bank `coverage.dedupe_v1_11` block.
- `tools/build_v1_11_dedupe.py` is idempotent (`--check` verifies without writing); content lives in `tools/v1_11_content_dedupe.py`.
- Version metadata (package, API, README, manifest, footer) set to 1.11.0; PWA cache key `sm-school-ai-v1.11.0-dedupe`.

## Safeguards
- All new items remain `platform_practice_not_official`; no official-sequence alignment is claimed and no secondary pathway is assigned.
- Language and editorial review remain pending; teacher review is required before classroom use.
- The cost question in one electricity item uses a hypothetical price (5 DA per kWh) and says so in its wording; it is not an official tariff.

## Not changed (still open)
- The term-1 items of the four middle-school physics and technology pairs (14-0067, 14-0148, 14-0226, 14-0304) still use a generic "organised learning" question that is not subject-specific; consider replacing them.
- 29 term-exam and 12 integrative answer-key entries for typed numeric items store the numeric result while the bank `solution` holds the worked line; this is intentional and unchanged.

## Validation
- Baseline v1.10.0 JavaScript tests and the two non-FastAPI Python tests passed before the change.
- Final run: all 22 JavaScript test files pass (the 21 existing files plus the new `dedupe_test.js`); `tests/release_integrity_test.py`, `tests/depth_pack_tool_test.py` and the new `tests/dedupe_tool_test.py` pass.
- `node --check` passed for all 39 JavaScript files; Python `compileall` returned exit code 0 for backend, tools and tests.
- Not executed in the authoring environment: the five FastAPI-based Python tests (curriculum, PDF candidate, tutor, parent auth, parent sync), because FastAPI cannot be installed offline, and therefore the complete `npm test` chain. The backend reads the bank generically and the changed records follow the same schema; run `npm test` in a normal environment before release.
- No Android APK build is included or claimed.
