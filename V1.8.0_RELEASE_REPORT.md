# SM SCHOOL AI v1.8.0 Release Report

## Scope
Added the AI Student Profile on top of v1.7.9. Existing server routes and educational content libraries were retained.

## Implemented
- Learner-scoped 90-day profile summaries and 30-day recent performance.
- Four-week accuracy trend using only recorded activity.
- Subject-level accuracy, activity counts, and optional topic/skill mastery when those fields exist in source records.
- Adjustable personal mastery target (60–100%), stored locally per learner.
- Weekly and monthly shareable text reports and learner-specific CSV export.
- Conservative advisory signals: insufficient data remains explicit; attention indicators require adequate activity and are not diagnoses or deterministic predictions.
- Profile goal data included in local backup/restore and removed when a learner profile is deleted.
- PWA cache namespace, manifest, frontend and backend version metadata updated to v1.8.0.

## Data and privacy
- Profile analytics are computed locally from existing progress records.
- No new server endpoint or third-party data transfer was introduced.
- Existing learner IDs are used to prevent sibling data mixing.
- Topic-level indicators are omitted when the underlying activity records do not contain topic/skill metadata.

## Validation
- Full `npm test` regression suite passed, including the new `student_profile_test.js`.
- JavaScript syntax checks passed for all `web/*.js` files.
- Python compilation passed for backend, tests and tools.
- Android APK build was not run; release ZIP contains the source project.
