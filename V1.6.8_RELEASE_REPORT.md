# SM SCHOOL AI v1.6.8 — Release report

## Delivered
- `web/family-planner.js`: daily schedule and 7-day parent report for every learner profile, shown on the parents page.
- Weak subjects (3+ scored activities, accuracy under 50%) take the first session of each study day.
- Share/copy text report and CSV export; backup/restore and profile deletion cover `smSchoolFamilySchedule`.
- New test `tests/family_planner_test.js`, added to `npm test`.

## Limits
- Suggested home routine only; not the official Ministry timetable.
- Subject lists come from the app's grade index, which is still pending official curriculum verification (see CURRICULUM_GOVERNANCE_2026-2027.md).
- Weekdays use UTC dates, matching how the app already stores progress dates.
- Not built as APK and not tested on a physical device.
