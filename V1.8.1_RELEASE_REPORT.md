# SM SCHOOL AI v1.8.1 — Release report

## Scope
Learner-specific exam readiness and a five-day adaptive revision plan, built on the v1.8.0 learner profile. This is a UI and local-logic release; backend routes and server behavior are unchanged.

## Delivered
- Readiness indicator is withheld until at least 30 answers across 3 activities are recorded.
- Once sufficient evidence exists, a 0–100 advisory score is calculated from overall accuracy and a capped recent trend adjustment. It is not a predicted exam grade or a guarantee of success.
- A five-day revision plan prioritizes recorded topics and subjects below the learner's personal mastery target.
- Tasks include practical review and practice suggestions, with a copy-plan action.
- Arabic, French, and English interface text.
- Learner data remains locally scoped to the active learner; no new network calls or backend endpoints.

## Validation
- Regression and feature tests run via `npm test`.
- JavaScript syntax checks run across `web/*.js`.
- Python compilation checks run for backend, tests, and tools.
- ZIP archive integrity checked with `unzip -t`.
- Android APK build is not included in this source ZIP.
