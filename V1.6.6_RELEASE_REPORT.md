# SM SCHOOL AI v1.6.6 — Release report

## Scope delivered
- AI tutor requests now include the active learner's display name and a bounded summary of recorded subject performance.
- The backend tutor prompt uses that context only to prioritize supportive explanations; it does not infer a diagnosis, assign an official grade, or claim verified curriculum alignment.
- Tutor conversation history is stored locally per learner, limited to the latest 30 exchanges, and restored when switching between learner profiles.
- Users can clear the active learner's tutor history. Deleting a learner also deletes that learner's tutor history.
- Tutor histories are included in local JSON backup/restore with JSON array validation.
- Groq API integration and existing demo fallback remain unchanged.

## Preserved
- All v1.6.5 source files and features, exercise/test banks, content indexes, Android Capacitor wrapper, and offline PWA assets.
- No AI API key is stored in the browser. No cloud storage or cross-device synchronization is claimed.

## Privacy and limitations
- If Groq is configured, the learner name and compact subject-performance summary are sent to the configured backend as part of the tutor request. Do not include sensitive personal information in learner names or questions.
- Conversation history remains in this browser/app installation and is not encrypted or synchronized.
- AI explanations and generated practice remain supplemental and require adult/teacher review; they are not official ministry materials.
