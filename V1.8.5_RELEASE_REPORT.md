# SM SCHOOL AI v1.8.5 — Parent account protection

## Scope
Security hardening for parent-only sign-in. Student and teacher accounts remain unsupported. No student records or learning data are moved to the server by this change.

## Delivered
- Added persistent sign-in throttling for both normalized account email and client IP.
- Five failed sign-in attempts within a 15-minute rolling window trigger HTTP 429.
- Responses include a `Retry-After` header; expired attempts are pruned automatically.
- Successful authentication clears the matching account and IP failure buckets.
- Bucket identifiers are SHA-256 hashes; raw IP addresses and email addresses are not written to the attempt table.
- Existing parent registration, sessions, password changes, encrypted device transfer, learning APIs and account roles are unchanged.

## Operational notes
- This is an application-level baseline, not a substitute for a reverse proxy/WAF rate limit in production.
- Deploy over HTTPS and use a persistent private database volume.
- If the app runs behind a reverse proxy, configure trusted proxy handling at the deployment layer before relying on client IP throttling.
