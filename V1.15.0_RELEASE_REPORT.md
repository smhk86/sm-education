# SM SCHOOL AI v1.15.0 — Curriculum progress and learner tracking

## Changes
- Added a learner-specific curriculum progress tracker to the home study centre.
- Learners/parents can record actual lesson titles, grade, subject, term, progress status, and optional textbook/page reference.
- Supports planned, in-progress, mastered, and needs-review states.
- Progress data is isolated by active learner and stored locally on the device.
- Added JSON export for the active learner's progress record.
- Explicitly avoids inventing official lesson titles or claiming Ministry verification.
- Updated app/package/backend metadata and service-worker cache version.

## Validation
- Full project test suite is required for release.
- JavaScript syntax checks and archive integrity checks are required.
- Android APK is not claimed unless built and device-tested.

## Known limitations
- The tracker records lessons entered by the family; it does not certify official curriculum alignment.
- Current-year Ministry annual progressions still require human review against exact document pages.
- Android Gradle project generation/build remains a separate deployment task.
