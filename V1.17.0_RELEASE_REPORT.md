# SM SCHOOL AI v1.17.0 — Timed practice exams

## Implemented
- Added countdown timer to the existing practice exam renderer.
- Prepared term papers use their configured duration.
- Generated tests use a transparent estimate (2 minutes/question, minimum 10 minutes).
- Visual warning during the final minute.
- Automatic submission when time expires.
- Timer cleanup on submission and rerender.

## Validation
- Dedicated module syntax/contract test.
- Full project test suite.
- Archive integrity check.

## Scope and limitations
- The feature applies to platform practice tests; it does not turn platform-authored papers into official Ministry exams.
- APK build and physical-device validation are not claimed.
