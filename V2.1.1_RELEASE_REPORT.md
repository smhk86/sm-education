# SM SCHOOL AI v2.1.1 — Groq Direct Migration

- Removed the previous external AI provider integration and all of its credential/model configuration.
- Groq is now the sole live generative-AI provider for the in-app tutor and assistant.
- Added direct client routing for both `/api/v1/ai/tutor` and legacy `/api/v1/ai/chat` requests when a user key is configured.
- Groq key and model are configured in the app; no API key is bundled in source code or APK. The user-entered key is kept in this device’s local app storage.
- Server endpoints remain local/offline fallbacks and no longer call an external AI provider.
- Existing offline exercise-bank fallback remains available.

Security note: a user-entered key stored on-device is still accessible to someone with access to the device/app data. Do not embed a shared secret in a distributed APK; production shared-key use requires a secured backend proxy.
