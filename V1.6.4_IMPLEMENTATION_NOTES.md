# SM SCHOOL AI v1.6.4 — Release notes

## Changes
- Added guarded in-app back navigation. Back now returns through the in-app page history; at the home screen, leaving requires confirmation.
- Added a visible back control in the top bar.
- Refined responsive layouts for mobile screens, learning cards, content panels, filters and archive link actions.
- Added publisher/source-page fallback links beside direct PDF links in both the external exam directory and the historical archive. A source-page fallback is shown because a publisher may move or block a direct PDF URL.
- Added 8 platform-authored Grade 3 Primary practice items with answer choices, solutions, explanations and step-by-step reasoning.

## Targeted learning-bank coverage
- Grade 1 Secondary: 131 exercises; 30 term papers with answer keys.
- Grade 2 Middle: 131 exercises; 30 term papers with answer keys.
- Grade 3 Primary: 100 exercises; 21 term papers with answer keys.
- All term-paper answer keys are included in the local term-exam dataset. These papers are platform practice materials, not official Ministry papers.

## Verification and limitations
- `node tests/smoke_test.js`: passed.
- `python tests/curriculum_api_test.py`: 5 tests passed.
- No APK was built: the archive has no generated Android Gradle project, and this environment has not been configured with the Android SDK/Gradle toolchain.
- External PDF availability still depends on publishers and internet access. The app now offers the source page as a fallback; it cannot guarantee that a third-party publisher's file remains online.
- New practice content is platform-authored and needs teacher review. Official 2026–2027 subject/lesson alignment remains unverified where the source register says so.
