# SM SCHOOL AI v1.7.1 — Release report

## Delivered
- Study consistency panel on the progress page.
- Current streak, best streak and total unique study days, derived from the active learner's existing activity history.
- Duplicate activity records on the same date count as one day.
- Current streak allows a one-day gap when the latest activity was yesterday.
- Added `tests/study_streak_test.js` and integrated it into the test script.

## Privacy and limitations
- No new data is collected or transmitted. The panel uses the existing locally stored progress records.
- The streak measures recorded app activity, not total time spent studying away from the app.
- Existing UTC-based activity date storage is retained for compatibility.

## Verification
- JavaScript syntax check and targeted streak tests are included in this release workflow.
- APK compilation/device testing is not claimed by this source-only release.
