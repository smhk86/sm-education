# SM SCHOOL AI v1.6.3 implementation notes

## Delivered in this source update
- UI refresh, responsive spacing, refined cards and persistent light/dark appearance.
- Offline glossary additions in five languages. Word/phrase matching remains dictionary-based and sentence translation is approximate, not neural machine translation.
- Six additional computing and AI lessons: data literacy, Python, networks, databases, cybersecurity and AI ethics.
- Two additional applied exercises per indexed subject for Grade 3 Primary, Grade 2 Middle and Grade 1 Secondary (Science & Technology common core subject candidates), plus one new integrative situation per subject.
- External archive result rendering now accepts direct PDF links where present and falls back to source pages when the synchronization index has no individual records.
- The legacy server-side provider integration has been retired. Live tutoring now uses the direct in-app Groq client; never hard-code a key in web/config.js or APK assets.

## Important limits
- No Claude-generated materials are claimed in this archive: there is no Anthropic API credential or verified Claude generation run in this environment. New items are platform-authored drafts and require teacher review.
- The exercise/situation additions are supplemental practice and are not ministry-approved or a substitute for official annual progressions.
- Direct PDF downloads depend on source publishers and network availability. The project contains two candidate PDF URLs in the acquisition index; rights and authenticity remain unverified.
- A working APK cannot be built in this environment without Android SDK/Gradle dependencies; source and web tests are run separately.
