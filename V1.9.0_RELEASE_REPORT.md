# SM SCHOOL AI v1.9.0 — Long-term learner memory

## Scope
Add a private, learner-scoped longitudinal summary that uses existing local learning records. No new AI provider, API route, or automatic external data transfer is introduced.

## Delivered
- Long-term performance summary by subject across the learner's recorded history.
- Evidence bands: limited (<5 answers), moderate (5–19), strong (20+); accuracy is omitted when there is no evidence.
- Recurring recorded mistake labels appear only after at least two occurrences.
- Counts of optional written reasoning records, without copying raw reasoning into memory snapshots.
- Optional dated snapshots, capped at 52 per learner and 520 total; same-day saves replace the same learner's prior snapshot.
- Memory display integrated into the learner profile.
- Local backup compatibility and learner deletion lifecycle support.

## Privacy and safeguards
- All calculations run locally in the browser.
- Data remains scoped to the active learner.
- No diagnostic, predictive, or causal claim is made from the records.
- No reasoning text is sent externally by this feature.
- Snapshot records contain aggregate summaries rather than raw learner answers or reasoning.
