# SM éducation v2.4.0

منصة تعليمية جزائرية متعددة المستويات، تضم بنك التمارين والمناهج والمكتبة والمعلم الذكي وفضاء الأولياء وأدوات التخطيط والتقدم الدراسي.

## v2.4.0 — محادثة للمساعد الذكي وبنك تمارين أذكى وتنقل أبسط
- المساعد الذكي بواجهة محادثة: شريط كتابة ثابت، فقاعات، تنسيق آمن، أزرار اقتراح وأنواع مساعدة.
- بنك التمارين: تدريب سريع مختلط، شارات إتقان ومراجعة، شريط تقدم أثناء الجلسة.
- التنقل: زر «المزيد» في الشريط السفلي وشريط تبديل التمارين/الاختبارات.

## v2.3.1 — إصلاحات وموثوقية البناء
- إصلاح نصوص فرنسية مكسورة في مكتبة dzexams، وتخزين PDF.js مسبقاً للعمل دون اتصال.
- مهمة اختبارات في GitHub Actions قبل بناء APK، وتوقيع اختياري عند غياب المفتاح.
- تنظيف `.gitignore` وتحسين إمكانية الوصول لزر الإشعارات.

## v2.3.0 — التحميل المباشر من dzexams.com وتحسينات بنك التمارين
- استُبدل سكريبت تحميل تسنيم بمكتبة داخل التطبيق تحمّل الامتحانات والفروض من dzexams.com مباشرة بعد إقرار المستخدم بموافقة أصحاب الموقع.
- من «بنك الاختبارات» افتح بطاقة dzexams، فعّل الإقرار، والصق رابط صفحة المستوى أو المادة، ثم حمّل الملفات. يُحفظ آخر رابط لكل مستوى، وتُصنَّف الملفات حسب المادة مع فلتر مادة.
- يعمل الجلب داخل تطبيق Android (عبر CapacitorHttp)؛ في المتصفح العادي يفشل غالباً بسبب CORS. التفاصيل في `CONTENT_FEED_DEPLOYMENT_AR.md`.
- بنك التمارين: بطاقة «تابع من حيث توقفت» (آخر مادة فتحتها في المستوى) وبطاقة «تحدّي اليوم» (مادة تتغير يومياً بحسب المستوى).

## v2.2.2 — تطوير بنك التمارين والاختبارات وتحسين الواجهة
- تحسين اكتشاف التمارين عبر البحث الفوري عن المواد وإظهار عدد الأسئلة المتاحة للسنة والمادة.
- إضافة مرشحات سريعة لإظهار المواد التي تتضمن تمارين للمبتدئين أو للمستوى المتقدم.
- عرض توزيع أسئلة الاختبار حسب الفصول قبل بدء الاختبار.
- تحسين التباين والمساحات والاستجابة للشاشات الصغيرة وحالات التركيز والاختيار.
- الحفاظ على بنك المحتوى الحالي دون توليد أسئلة غير موثقة أو الادعاء بمطابقة وزارية غير مثبتة.
- تحديث رقم الإصدار وذاكرة التخزين المؤقت وإضافة اختبارات انحدار للتحسينات.

## v2.2.0 — موثوقية التحديث والعمل دون اتصال
- صفحات التطبيق وموارده البرمجية تتصل بالشبكة أولاً لتفادي بقاء نسخة قديمة، ثم تستخدم النسخة المخزنة عند فشل الاتصال.
- موارد التطبيق الأساسية مطلوبة عند تثبيت Service Worker؛ أما الموارد الاختيارية والملفات الثقيلة فتحمّل بأفضل جهد.
- تفعيل العامل الجديد والسيطرة على الصفحات المفتوحة بعد التنشيط، مع تنظيف ذاكرات الإصدارات السابقة.
- اختبار آلي يتحقق من وجود جميع مسارات التخزين المسبق.

## التشغيل
- `npm test` — مجموعة الاختبارات والتحقق من سلامة المحتوى.
- `npm run serve` — تشغيل واجهة الويب محلياً على المنفذ 8080.
- `npm run android:sync` — مزامنة موارد Capacitor إلى مشروع Android بعد تثبيت الاعتماديات.
- `npm run android:build:debug` — بناء APK تجريبي عند توفر Android SDK وGradle wrapper.

## حدود التحقق
اجتياز الاختبارات الآلية لا يعني أن APK بُني أو أن التطبيق اختُبر على هاتف فعلي. يجب تنفيذ البناء والاختبار على بيئة Android مجهزة قبل إعلان الجاهزية للتثبيت.
