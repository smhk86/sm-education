# SM SCHOOL AI v1.8.9 — Smart teacher reasoning coach

## Scope
Extend Smart Teacher from answer checking to optional capture and review of the learner's reasoning process. The feature reuses the existing AI tutor endpoint; no new provider or API route is introduced.

## Delivered
- Added an optional, bounded reasoning text field to each Smart Teacher question.
- Captures the selected answer, expected answer, correctness, question explanation and learner reasoning.
- Stores a learner-scoped local reasoning journal, capped at the latest 500 entries.
- Adds an explicit action to submit the current learner's reasoning to the existing AI tutor endpoint for formative analysis.
- Clearly distinguishes an actual provider response from demo mode; errors do not erase local records.
- Adds the reasoning journal to local backup/restore validation and learner deletion lifecycle.
- Updates package, API, PWA cache, manifest and release documentation to v1.8.9.

## Privacy and compatibility
- Reasoning text remains local unless the user explicitly presses the analysis action.
- Records are scoped by learner ID and removed with that learner's profile.
- Existing backup version remains unchanged; the new key is an optional backward-compatible field.
- AI analysis uses the existing configured server endpoint and its existing quota/provider settings.
