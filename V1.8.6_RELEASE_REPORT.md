# SM SCHOOL AI v1.8.6 — Transaction-safe backup restore

## Scope
Harden local JSON restore and parent-authorized encrypted device transfer against partial writes caused by browser storage failures (for example, quota exhaustion).

## Delivered
- Added one shared transactional restore helper for local backup files and encrypted parent device transfers.
- Captures the prior values of all managed backup keys, including per-learner exercise mistakes and tutor histories.
- Applies replacement only to managed learning-data keys; unrelated local settings remain untouched.
- If any removal or write fails, attempts to restore the complete previous managed-key state before reporting the failure.
- Reuses the existing backup schema validation and user confirmation; no new server storage or student-data upload was introduced.
- Bumped app/API/PWA release metadata to v1.8.6 and changed the service-worker cache key.

## Validation
- Added regression tests for successful replacement, preservation of unrelated keys, deletion of stale learner histories, and rollback after a simulated storage write failure.
- `npm test` completed successfully (exit code 0), including all existing frontend, backend, authentication, encrypted-transfer and new transactional-restore tests.
- Python bytecode compilation and ZIP integrity checks completed before packaging.
- APK build is not included in this source ZIP.
