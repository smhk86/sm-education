# SM SCHOOL AI v1.18.0 — Weekly home study planner

## Implemented
- Added a learner-specific weekly revision planner in the home learning centre.
- Configurable daily study minutes.
- Add study sessions by subject, day and priority.
- Generate a starter weekly distribution across up to five subjects.
- Mark sessions complete, remove sessions, and view planned minutes/completion count.
- Local-first storage separated by active learner; no network or AI key required.
- Updated app version and service-worker cache key/precache list.
- Added a dedicated regression test.

## Validation and limitations
- Dedicated JavaScript syntax/contract test included.
- Full test suite should be run in the project environment with dependencies available.
- This is a flexible home revision planner, not an official school timetable.
- Official 2026–2027 curriculum alignment remains a separate verification task.
- Android APK build and physical-device validation are not claimed.
