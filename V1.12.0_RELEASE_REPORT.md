# SM SCHOOL AI v1.12.0 — Quality, security and loading pass

## Scope
Fix defects found in the v1.11.1 audit that do not need an official source. No official lesson sequence is claimed; no new questions, situations or subjects were authored.

## Delivered
- **Answer positions**: 1,306 legacy multiple-choice items rebalanced (0/1/2 = 509/513/500; before, 52% had the correct answer first). Depth-pack and dedupe-replacement records were already balanced and are untouched. Exam / situation answer keys store the answer text, so they remain valid (checked in `tests/quality_v1_12_test.js`).
- **Cross-grade repeats**: 983 records (158 identical subject+question pairs repeated across grades) get `quality_flags: ["cross_grade_repeat"]` and `repeat_grades`. They are flagged, not deleted (ids are used by exams). Worklist: `CROSS_GRADE_REPEAT_WORKLIST.csv`.
- **Situations**: written rubric is now four criteria in the Algerian style (relevance, correct use of subject tools, coherence, mastery), `rubric_basis: platform_adaptation_of_four_criteria_pending_official_verification`.
- **Backend**: 16 routes (PDF review, OCR, layout, candidates, evidence, `ai/claude-content`) require `X-Admin-Token`; closed by default (`ADMIN_TOKEN`; `ALLOW_OPEN_REVIEW_API=1` for local dev). Groq key moved from the URL to the `Authorization: Bearer` header. In-app field to store the admin token.
- **Loading**: exercise bank fetched once (`smFetchJSON`), service worker pre-caches bank, term exams and situations (non-fatal) and removes old caches.
- **Pipeline**: `tools/build_v1_12_quality.py` is idempotent and chained at the end of `build_v1_11_dedupe.build()`, so the generator tests still match the committed data.
- `OFFICIAL_PROGRAMME_CHECKLIST.md` lists the official documents needed for the pilot levels.

## Not done (needs input or is out of scope)
- Official programme mapping (needs the ministry documents), stream-specific secondary subjects, new subjects (Amazigh, arts, music, PE), grade-specific rewrites of the 158 repeated questions, hand-written integrative situations, 4-choice questions.
- File download route `/pdf-review/{id}/file` cannot carry the token from a plain link/iframe; open it through the app with the token set or fetch it as a blob.
- AI quota is still in memory and per IP.

## Validation
- All 23 JavaScript test files pass (including the new `quality_v1_12_test.js`); `release_integrity_test.py`, `depth_pack_tool_test.py`, `dedupe_tool_test.py` pass; `node --check` on all web scripts; Python `compileall` OK.
- Not executed: the five FastAPI-based Python tests (FastAPI not installable offline), so the admin guard is syntax-checked and asserted in the JS test but not exercised over HTTP. `pdf_candidate_api_test.py` and `curriculum_api_test.py` set `ALLOW_OPEN_REVIEW_API=1` (edited without being run) — run `npm test` in a normal environment.
- No APK was built.
