# SM SCHOOL AI v1.7.2 — Release report

## Delivered
- Home school (المدرسة المنزلية) page: per-learner guided school day and suggested weekly timetable.
- Session = lesson → exercises → mistake review, each with its own completion checkbox and a button that opens the matching tool for the child's grade and subject.
- Weekly timetable spreads each subject over the chosen study days (default Sunday–Thursday) without repeating a subject within a day; weekly load per subject; seven-day completion summary.
- Subjects follow the grade (English from primary year 3, French from year 4). Secondary uses the common subject list; stream-specific matrices are not modelled.
- Local storage only (`smSchoolHomeSchool`), included in backup/restore and removed with the learner.

## Limitations
- Sessions per week and session length are suggested home-routine values, not official Ministry hours or coefficients.
- Step completion is ticked by the parent/learner; only the day's recorded exercise activities are shown as a hint.
- The lesson step uses the starter lesson library, which covers few lessons per subject; the textbook remains the main source.

## Verification
- Node tests (smoke, streak, adaptive, family planner, offline tutor, home school) and the release integrity test pass; all web scripts pass a syntax check.
- Python API tests need FastAPI and were not run in this environment.
- No APK was built or device-tested; this is a source-only release.
