# SM SCHOOL AI v1.7.3 — Release report

## Delivered
- 79 supplemental lessons (goal, explanation, check question, answer) for Grade 3 Primary, Grade 2 Middle and Grade 1 Secondary common core, covering every subject indexed for those grades (at least 2 lessons each).
- Home school lesson step opens a lesson of the child's grade and subject and moves to the next lesson as completions are recorded.
- Lesson library shows the selected grade's lessons first.

## Limitations
- Lessons are short supplements that do not replace the textbook or the official progression; they are not mapped to verified Ministry units, and teacher review is required before relying on them.
- New lessons are mostly in Arabic (language-subject lessons are in the target language); French/English interface languages show the Arabic text.
- Secondary lessons cover the common core only; stream-specific subjects are not covered.
- Other grades still have only the original starter lessons.

## Verification
- Node tests pass (smoke, streak, adaptive, family planner, offline tutor, home school, extra lessons) and release integrity test passes; all web scripts pass a syntax check.
- Python API tests need FastAPI and were not run here. No APK built or device-tested.
