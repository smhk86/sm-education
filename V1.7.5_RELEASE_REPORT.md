# SM SCHOOL AI v1.7.5 — Release report

## Base
- Continued directly from the supplied `SM_SCHOOL_AI_v1.7.4` source package.
- Preserved the existing application, backend, curriculum datasets, lesson banks, assets, Android wrapper, and prior release documentation.

## Added
- Parent portal now includes a rolling seven-day learning summary.
- Shows activity count, overall answer accuracy, and per-subject activity/accuracy.
- Support recommendations require at least five recorded answers and accuracy below 60%.
- Strong-subject indicators require at least five recorded answers and accuracy of at least 85%.
- If there is insufficient activity, the panel says so rather than guessing.
- The panel is available in Arabic, French, and English.
- The UI explicitly says that the analysis is guidance from locally stored results, not an official assessment.

## Validation
- `npm test`: passed (all configured Node.js and Python test suites).
- `node --check web/app.js`: passed.
- `python tests/release_integrity_test.py`: passed.
- The full source ZIP was created and checked for ZIP integrity.

## Important curriculum note
This release improves parent follow-up; it does not claim that all lesson sequences, competencies, coefficients, or assessment content have been officially verified. Official curriculum alignment remains governed by the source register and verification workflow already included in the project.
